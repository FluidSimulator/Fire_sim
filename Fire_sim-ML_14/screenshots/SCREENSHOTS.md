# screenshots/

Drop your captured screenshots here and update the image paths in `README.md`.

## Suggested filenames

| File | What to capture |
|---|---|
| `banner.png` | Full window at ~5 s of simulation – tall rising flame |
| `smoke_rising.png` | After ~15 s – wide smoke plume above the flame |
| `click_burst.png` | Mid-click showing the extra fire burst from the cursor |
| `campfire_preset.png` | Campfire preset from README parameter guide |
| `inferno_preset.png` | Inferno preset – massive roaring fire |

## How to take a screenshot on Linux

```bash
# Press Print Screen while the window is focused,  or:
scrot -s screenshots/banner.png   # interactive region select
```

## How to take a screenshot on Windows

Press `Win + Shift + S` to open the Snipping Tool and save to this folder.
